# Kado Academia — prévia de repaginação

Prévia comercial independente, **não é o site oficial** da Kado Academia. Conteúdo, fotos e vídeo vêm de fontes oficiais e estão sujeitos à aprovação da academia e dos direitos de imagem. Proposta de Bruno Luque.

```bash
npm ci
npm run dev        # http://127.0.0.1:3037
npm run typecheck
npm test
npm run build
```

Publicada com GitHub Pages por `.github/workflows/deploy-pages.yml`. A página usa `noindex` enquanto for prévia.
